# Gym Frontend Project

A simple, responsive website for a gym created as part of a university project. This project showcases the use of **HTML**, **CSS**, and **JavaScript** to build an engaging and interactive user interface.

## 📋 Features

- **Home Page**: A visually appealing landing page with gym details and a welcome message.
- **About Us**: Information about the gym, trainers, and facilities.
- **Classes**: A section displaying different classes and schedules.
- **Membership Plans**: Details about various membership packages.
- **Contact Us**: A form for users to reach out with inquiries.

## 🛠️ Built With

- **HTML**: Structuring the content of the website.
- **CSS**: Styling the website for a modern and responsive look.
- **JavaScript**: Adding interactivity (e.g., form validation, interactive buttons, etc.).
